# Dahyacob · tienda online

React + Vite + TypeScript + Tailwind. Pedidos por WhatsApp (+57 315 095 0719).

## Comandos
- `npm install` · `npm run dev` · `npm run build`
- Publicar en GitHub Pages: sube el repo, `npm run build` y publica la carpeta `dist` (por ejemplo con `npx gh-pages -d dist`). `base: './'` y las rutas con `#` funcionan bajo cualquier nombre de repo.

## Fotos
Pon el logo en `public/img/logo.png`. Cada modelo usa `public/img/<subcategoria>/<modelo>-1.jpg` y `-2.jpg`
(la ruta exacta sale de `src/data/products.ts`). Mientras no existan se ve un marcador rosado.
